# Capability inventory

Source basis: Super Productivity commit `54a3793` (package `19.1.0`), especially `src/app/features/tasks/task.model.ts`, `packages/plugin-api/src/types.ts`, `src/app/core/electron/local-rest-api-handler.service.ts`, `src/app/plugins/plugin-bridge.service.ts`, `src/app/features/tasks/task.service.ts`, and repeat/attachment/board/section models. API availability may differ by installed release.

Legend: REST = local REST routes; Plugin = public plugin API. Status describes actual MCP availability and evidence: stock REST read/write, derived/read-only, enhanced write, unsafe, unsupported, excluded, or live-verified. `LIVE_VERIFIED` means an actual MCP client changed a rebuilt app with disposable data and checked persisted state; `DONE` may have local test coverage without live proof.
