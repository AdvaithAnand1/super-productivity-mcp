# Project state

- **Scope:** This community fork expands the original Super Productivity MCP with richer task context, sparse metadata updates, bounded bulk operations, and capability-gated semantic operations.
- **Capability boundaries:** `docs/FEATURES.md` is authoritative. Recurrence writes, local file/image attachments, attachment binary transfer, provider-specific issue metadata edits, and board/section membership writes remain unsupported or read-only. Link attachment creation, title-only rename, and metadata detach are supported.
- **Enhanced app API:** Compatible Super Productivity 19.1.0 source build; authenticated loopback only. Capabilities cover priority, hierarchy, ordering, historical time, constrained project/tag administration, and link attachment metadata. Project deletion requires an empty project; tag deletion is blocked while in use and Today is protected.
- **Integration evidence:** MCP operations were exercised through real STDIO clients against disposable app profiles and entities. Priority, hierarchy, project/Today/subtask/backlog order, manual time, project/tag administration, task metadata, and link attachment lifecycle were read back and verified. Disposable test entities were removed.
- **Verification:** `pnpm verify` passes lint, format, typecheck, 63 tests, and build. `pnpm pack:check` passes. `pnpm smoke:package` installs the tarball in a fresh prefix, initializes STDIO, enumerates all 29 tools, confirms the token-free Windows Codex template is packaged, and verifies the expected `SP_UNREACHABLE` response when the app is absent. The package contains 46 files (60.9 kB).
- **Windows support:** The MCP package smoke and full check pass natively on Windows. The compatible app source build passed its Windows distribution pipeline on pinned Node 22.18.0; the unpacked x64 app passed live MCP metadata and attachment checks using an isolated profile. See the release runbook for the tested workflow.
- **Security:** The enhanced API is restricted to loopback and existing Bearer authorization. Routes map to explicit validated operations; there is no generic state setter or arbitrary service invocation. Tokens are not logged. The released stock app supports standard operations; enhanced mutations require an app build advertising the relevant capability.
- **Distribution:** The GitHub repository is the supported distribution for this fork. The package name is shared with the original published npm distribution; this fork has not been published to npm. Use a local checkout for this fork until a separately authorized package release.
